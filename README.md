# 东方怪绮谈 · 非官方独立重制

**仅供交流学习使用。**

《东方怪绮谈》的 Windows x64 非官方独立重制版。本仓库用于发布游戏安装包、使用说明和作者署名。

## 下载

打开本仓库的 **Releases**，下载最新版本：

- **MysticSquare-1.0-OneFile.exe**：单文件版，双击即可自动展开完整游戏并启动。
- **MysticSquare-1.0-Windows-x64.zip**：便携版，解压后双击「开始游戏.cmd」，保留完整 Build 文件夹。
- **SHA256SUMS.txt**：下载文件的 SHA-256 校验值。

不需要安装 Unity、模拟器或原作游戏。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 | 移动、菜单选择 |
| Z / Enter | 确认、推进剧情；按住 Z 射击 |
| Shift | 低速移动 |
| X | Bomb、菜单返回 |
| Esc | 暂停、返回 |
| F1 | 切换无敌（默认关闭，设置中也可切换） |
| F11 | 全屏、窗口 |
| Ctrl | 跳过当前剧情段落 |

## 内容

四名自机、六关主线、Extra、四档主线难度、角色结局、音乐室、音量设置和最高分保存。

1.0.0 已修正窗口缩放下的 HUD 图标偏移与斜向激光提前截断。211 项模拟检查、两种窗口尺寸的激光显示检查及单文件启动烟测通过。

## 还原范围与署名

依据公开文字资料独立重建。剧情为精简中文重述；音乐采用独立转谱重新合成，部分为钢琴 Easy 编曲；弹幕时序、轨迹和 Rank 参数未与原作逐帧校准。

未使用原版程序、ROM、图像、音频、官方 MIDI 或关卡脚本。

原作、角色设定与曲目作曲：ZUN／上海爱丽丝幻乐团。相关权利归各自权利人所有，本项目不代表官方。请阅读 [使用说明](NOTICE.md) 和 [音乐作者及来源](MUSIC-CREDITS.md)。
